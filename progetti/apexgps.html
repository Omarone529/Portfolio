Web App · Django & React

ApexGPS

Un servizio che calcola percorsi pensati per essere goduti, non solo percorsi.

Django PostGIS React Docker Azure

Il progetto

ApexGPS calcola percorsi panoramici basandosi su punti di interesse e sulla sinuosità delle strade, tramite un algoritmo custom che privilegia la bellezza del tragitto rispetto alla velocità. Il backend geospaziale elabora i dati stradali con PostGIS, mentre il frontend restituisce un'esperienza fluida e immediata.

Funzionalità principali

  • Algoritmo di scoring custom basato su curvatura e punti di interesse
  • Ricerca di percorsi panoramici a partire da un punto di partenza
  • API REST containerizzata e distribuita su cloud Azure
  • Interfaccia mappa reattiva costruita in React

Stack tecnologico

Django Django REST framework PostgreSQL PostGIS React Tailwind CSS Docker Azure
